📌 Project Overview

The Employee Salary Prediction System is a Machine Learning-based web application that predicts employee salaries using professional and demographic factors such as job role, experience, education level, skills, industry, company size, location, remote work status, and certifications.

The project includes:

Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
Machine Learning Model Development
Power BI Dashboard Creation
Streamlit Web Application Deployment
🎯 Project Objectives
Analyze employee salary-related factors.
Identify key features influencing compensation.
Build a Machine Learning model for salary prediction.
Deploy the model through an interactive Streamlit application.
